# 策略研究与探索

`codex-strategy-research` 服务于 `btc-updown-marketmaker` 的 Polymarket 做市研究：A 路线采用人工固定规则，B 路线采用机器学习或强化学习。它帮助研究者提出可检验问题，在批准范围和总预算内自主实验，并判断证据是否支持实际经营目标。

本仓库是私有规则源。它不保存交易数据、模型、实验结果或个人配置，也不替代交易项目的业务合同。研究组对业务仓库全部文件与 Git 内容只读；仓库外研究产物可写，研究主会话按授权维护 Issues／Projects。工程问题由用户审查后另行签发开发组。

## 使用

按[安装说明](docs/installation.md)安装后，普通启动即可，无需 `--profile`：

```bash
codex -C /absolute/path/to/btc-updown-marketmaker
```

在新会话中输入 `$`，从候选列表选择 `codex-strategy-research`，再追加研究请求。例如：

```text
$codex-strategy-research
继续 A 路线当前研究问题。先核对任务当前合同、已批准范围、数据用途和剩余预算。
在已有授权内自主准备、实验和分析；尚未批准的运行只准备具体提案。
```

也可指定 B 路线的研究问题。调用 skill 不提供新的运行预算，不启动训练服务器，不改变主会话的模型、推理等级或权限。研究职责的启用需要显式调用；后续子任务沿用同一轮授权，不要求用户重复调用。

在非交互入口中，仅传入字面 `$codex-strategy-research` 可能未展开正文；使用客户端正式 skill 选择或结构化 skill 输入。已核实的版本差异和只读验证方式见[安装说明](docs/installation.md)，不要为绕过该限制打开隐式调用。

## 工作方式

用户按研究问题批准一轮范围与总预算。主会话在范围内决定具体实验、并行安排和分析；只有超预算、数据用途、业务语义、评价条件、资源或资金承诺等实质变化才重新交用户决定。一次亏损、无成交或训练没有改善，可以是有效研究结果。

| 职责 | 负责什么 |
| --- | --- |
| 主会话 | 保持问题、授权、证据与预算连续；协调实验，维护任务事实，提出结论和最少裁决事项 |
| `research-designer` | 只读设计假设、反例、对照和证据需求 |
| `experiment-runner` | 只在仓库外准备获批配置、辅助分析、实验和产物，保留原始证据与实际成本 |
| `research-reviewer` | 独立只读审查数据资格、偏差、可比性、经营解释和外推边界 |

不要求每个小实验都走固定三角色流水线。A/B 共用角色，按任务加载各自方法。发现任何业务仓库文件问题都先向用户报告；研究主会话也不能自行转开发或派生开发代理。研究 Issue 保持当前约定与结论，评论保留方法和实验经过，Projects 展示进度，详细材料留在仓库外。

## 规则入口

- [共同研究流程](research/research-workflow.md)：授权、研究轮次、数据、预算、停止、证据和结论。
- [A：人工规则策略](research/rule-based-research.md)：机制、候选、解释性对照与经营证据。
- [B：学习策略](research/learning-based-research.md)：训练、模型选择、泄漏、随机性与冻结评价。
- [研究资料与方法借鉴](research/evidence-sources.md)：按问题使用互联网与项目知识库，核对原文、版本、证据状态和适用性。
- [工程交接](research/engineering-handoff.md)：缺陷证据、影响范围、修复与研究恢复。
- [案例验证](evaluations/scenarios.md)：用实际行为检查规则，不只检查文件格式。

`codex-governance` 继续维护通用工程原则和代码交付；本仓库维护研究方法；交易项目继续维护业务合同与研究结果。方法参考量化研究和机器学习一手资料，具体采用理由与适用局限见对应正文。

研究可按问题自主查阅互联网和 [research-knowledge](https://github.com/slowchillchill/research-knowledge)。本地知识库使用仓库外绑定的固定版本查询副本；安装说明给出位置与版本的配置方法。人工收录、论文报告和本项目复现是不同证据层次，研究不自动回写知识库。

更新本仓库后，在研究记录中明确采用的新版本及影响。已开始的一轮研究不能因 skill 更新而静默改变评价口径。安装、更新与回滚遵守[安装说明](docs/installation.md)。
